국가법령정보센터 원문

제12조(용역 공급의 특례)
① 사업자가 자신의 용역을 자기의 사업을 위하여 대가를 받지 아니하고 공급함으로써 다른 사업자와의 과세형평이 침해되는 경우에는 자기에게 용역을 공급하는 것으로 본다. 이 경우 그 용역의 범위는 대통령령으로 정한다.
② 사업자가 대가를 받지 아니하고 타인에게 용역을 공급하는 것은 용역의 공급으로 보지 아니한다. 다만, 사업자가 대통령령으로 정하는 특수관계인(이하 "특수관계인"이라 한다)에게 사업용 부동산의 임대용역 등 대통령령으로 정하는 용역을 공급하는 것은 용역의 공급으로 본다.
③ 고용관계에 따라 근로를 제공하는 것은 용역의 공급으로 보지 아니한다.
④ 제1항부터 제3항까지에서 규정된 사항 외에 용역의 공급에 관하여 필요한 사항은 대통령령으로 정한다.

02 / 쉽게 말하면초보자 해설

계약서상 판매자와 실제 공급자는 다를 수 있다. 재화의 인도, 용역의 수행, 가격결정, 하자·반품위험과 자금 귀속을 따라 자기 계산과 책임으로 공급한 주체를 찾는다.

1. 오늘의 목표와 30초 쉬운 설명 — 2분

쉬운 설명

30초 쉬운 설명

계약서에 판매자라고 쓰인 사람과 부가가치세법상 실제 공급자는 다를 수 있다. 재화는 지배가능한 가치 이전, 용역은 역무 제공이므로 물류·수행·가격위험을 따라 공급주체를 찾는다.

오늘의 목표

오늘 할 수 있어야 하는 것

  • 재화·용역 공급과 실제 공급자의 법정 요소와 경계를 순서대로 설명한다.
  • 재화·용역 공급과 실제 공급자 증거축은 A=출고지시 원본, B=하자보수 티켓, 미확인=출고권한 설정로그이다. 이 세 축으로 재화·용역 공급과 실제 공급자 조사측 설명과 납세자측 설명의 강도를 비교한다.
  • 공급가액·세액·귀속 과세기간을 계산해 별지 제21호서식 일반과세자 부가가치세 신고서의 관련 칸까지 닫는다.

먼저 판단하기

시작 전 판단

계약명의, 실제 인도, 계산과 책임을 세 열로 나누고 12대의 공급가액과 세액을 산출하자.

2. 핵심 용어와 법적 판단지도 — 4분

핵심 용어

핵심 용어

개념 현재 수업의 뜻 결정 증빙
재화 공급 계약상 원인에 따른 인도·양도 재고이동·검수

판단지도

법적 판단지도

  1. 법 제9조는 재화 공급, 제11조는 용역 공급, 제12조는 용역 공급의 특례를 정한다. 영 제18조의 위탁매매 등 재화 공급주체와 영 제25조 용역 범위를 실제 계약·인도·책임 사실에 맞춰 적용한다.
  2. 적용 조문 묶음은 부가가치세법 제9조·제11조·제12조 · 부가가치세법 시행령 제18조·제25조이다. 재화·용역 공급과 실제 공급자에서는 출고지시 원본 사실, ‘법 제9조에 따른 12대 재화의 실제 공급자가 플랫폼인지 창고업자인지가 쟁점이다.’ 요건, 별지 제21호서식 일반과세자 부가가치세 신고서 효과의 순서로 읽는다.
  3. 재화·용역 공급과 실제 공급자 수치는 ‘실제 인도수량 12대 × 대당 공급가액 100,000원 = 공급가액 1,200,000원; 세액 120,000원’으로 검산한다. 하자보수 티켓 금액이 부가가치세 별도인지 포함인지 먼저 확정한다.
  4. 자료 A(가격변경 이력)의 날짜와 공백항목(전자승인 IP)을 대조한다. 귀속표시: 2026년 제1기. 이어서 에스크로 정산서 거래키를 신고 칸까지 추적한다.

재화·용역 공급과 실제 공급자의 현행 기준은 [시행 2026. 1. 2.] [법률 제21065호, 2025. 10. 1., 타법개정], [시행 2026. 4. 1.] [대통령령 제36133호, 2026. 2. 27., 일부개정], [시행 2026. 4. 1.] [재정경제부령 제9호, 2026. 3. 20., 일부개정]이다. 출고지시 원본에는 현행 문언을 쓰고, 판례의 구법은 법 제9조에 따른 12대 재화의 실제 공급자가 플랫폼인지 창고업자인지가 쟁점이다. 범위에서만 전이한다.

적용 범위와 경계

대금이 한 계좌를 거쳤다는 사실만으로 공급자가 정해지지 않는다. 누가 재고손실·하자보수·가격변동을 부담하고 고객에게 이행을 약속했는지 거래 단계별로 쪼갠다.

심화 펼치기

심화

재화·용역 공급과 실제 공급자 심화대조는 작성시각(출고지시 원본)과 거래키(가격변경 이력)를 나누는 데서 시작한다. 공백항목=출고권한 설정로그. 이 항목이 비면 결론을 유보하고, 반증항목=전자승인 IP 확인 뒤 재화·용역 공급과 실제 공급자 포섭을 갱신한다.

05 / 조사·증빙세무조사 증빙 실습

조사 가설

플랫폼이 계약·하자창구·대금통제를 맡아 장비의 실제 공급자다.

반대 가설

창고업자가 재고·가격·반품위험을 부담하고 플랫폼은 중개용역만 공급했다.

먼저 확인할 자료

  • 출고지시 원본과 출고권한 설정로그
  • 하자보수 티켓과 비용 최종부담 전표
  • 가격변경 승인 IP와 관리자 이력
  • 에스크로 정산서와 환불손실 부담계정
