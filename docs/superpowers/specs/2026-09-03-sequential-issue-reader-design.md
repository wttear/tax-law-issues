# 순차형 세법 쟁점 리더 설계

## 목표

학습자가 여러 사실관계를 한꺼번에 기억하지 않아도 쟁점을 끝까지 따라가도록 한다. 각 단계는 `질문 → 새 사실 한 조각 → 관련 법령 → 답과 해설` 순서로 끝나며, 다음 단계는 앞 단계의 결론을 짧게 이어받는다.

## 독자에게 보이는 읽기 계약

1. **오늘의 질문**: 문서 첫 화면에서 판단할 문제를 한 문장으로 제시한다.
2. **단계 1**: 첫 질문을 펼치면 사실 한 조각만 나온다.
3. **관련 조문**: 그 질문에 필요한 법령만 보여 준다. 조문 전문은 접어 두고 공식 원문 링크를 제공한다.
4. **답과 해설**: 방금 주어진 사실과 조문만 사용해 결론을 설명한다.
5. **다음 단계**: 새 질문과 새 사실을 하나씩 이어 붙인다.
6. **마지막 정리**: 전체 결론을 한 번만 정리하고, 조사자료·판례·회계 연결은 해당 단계에 붙인다.

## 단계 데이터 계약

각 쟁점은 `steps` 배열을 가진다. 학습자에게 내부 참조번호를 기억시키지 않는다.

```json
{
  "step_no": 1,
  "question": "법인세 납세의무는 언제 생기는가?",
  "new_fact": "사업연도가 2025년 12월 31일에 끝났다.",
  "legal_refs": ["국세기본법 제21조"],
  "answer": "사업연도 종료일에 납세의무가 성립한다.",
  "explanation": "고지서 발급일이 아니라 과세기간의 종료시점을 본다.",
  "evidence": ["결산서", "사업연도 신고자료"],
  "precedent_refs": [],
  "accounting_note": null,
  "next_state": "납세의무 성립 시점 확인"
}
```

- `question`, `new_fact`, `legal_refs`, `answer`는 필수다.
- `evidence`, `precedent_refs`, `accounting_note`, `next_state`는 쟁점에 따라 비워 둘 수 있다.
- 전체 사실관계를 별도 서론에 다시 복사하지 않는다.
- `R1`, `R2` 같은 내부 ID는 검증용 데이터에만 둘 수 있지만 화면에는 표시하지 않는다.
- 같은 문장·같은 사실을 다른 단계에서 다시 쓰지 않는다. 바뀐 사실은 `changed_fact`와 그 결과만 별도로 표시한다.

## 페이지 구조

```text
쟁점 제목
└─ 오늘의 질문
   └─ 단계 1: 질문 → 새 사실 → 관련 조문 → 답·해설
   └─ 단계 2: 다음 질문 → 새 사실 → 관련 조문 → 답·해설
   └─ 단계 3: 다음 질문 → 새 사실 → 관련 조문 → 답·해설
└─ 판례가 바꾸는 경계 (해당 단계에 연결)
└─ 조사할 자료 (해당 단계에 연결)
└─ 사실이 달라지면 (변경 사실만)
└─ 마지막 정리
```

기존의 `법령과 쟁점의 판단지도`, `법적 판단지도`, `합성사례`, `결론의 이동`이라는 추상적 블록은 만들지 않는다. 필요한 판단은 각 단계의 질문과 답 안에 들어간다.

## 문장 원칙

- 결론을 선언하기 전에 독자가 볼 질문을 먼저 둔다.
- 한 문장에 한 판단만 담고, 날짜·금액·당사자·문서명을 가능한 한 적는다.
- “종합적으로 살펴보면”, “핵심적으로”, “다음과 같이” 같은 빈 연결어를 줄인다.
- 같은 결론을 요약·해설·마무리에서 반복하지 않는다.
- 법률 용어는 보존하되, 바로 뒤에 짧은 우리말을 붙인다.
- 확인되지 않은 판례의 판시나 사실을 보태지 않는다.
- 가상 사실은 `학습용 사례`라고 표시하고, 실제 사건처럼 꾸미지 않는다.

## 외부 편집 원칙의 적용

- [Deslop](https://github.com/fayerman-source/deslop)의 법률 문장 원칙에서 짧은 문장, 능동형, 전제-전제-질문 구조를 참고한다.
- [Slopspeare](https://github.com/davidvictor/slopspeare)의 규칙·체크리스트에서 상투적 서론, 추상적 중요성 선언, 결론 반복을 점검한다. 참고한 규칙은 저장소에 출처를 남긴다.
- [Your Voice](https://github.com/parasdoshicom/your-voice)의 근거·출처 우선과 사실 보존 검토를 적용한다.

이 원칙은 사람처럼 보이기 위한 가짜 말투나 탐지 회피가 아니다. 독자가 실제 판단에 사용할 수 있는 문장을 만들기 위한 편집 기준이다.

## 성공 조건

- 첫 화면에서 질문이 먼저 보인다.
- 한 단계 안에서 질문·새 사실·법령·답의 순서가 유지된다.
- 독자는 앞 단계의 전체 사실을 다시 읽지 않고 다음 단계로 넘어갈 수 있다.
- 같은 사례의 완전한 서술이 두 번 이상 출력되지 않는다.
- 원문은 필요한 단계에서만 펼칠 수 있다.
- 판례·증빙·회계 연결은 해당 질문을 해결하는 데 필요한 경우에만 나타난다.
